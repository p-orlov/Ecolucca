# Ecolucca

[![License: GPL-3.0-only](https://img.shields.io/badge/license-GPL--3.0--only-blue.svg)](LICENSE)

## What it is

Ecolucca is a fork of Felucca, alternative firmware for the FM-1 synth, that turns it into an evolving sound ecosystem: the first note you play seeds a cell, and cells then live, reproduce with small mutations, compete for frequency niches and die, so the sound grows an audible lineage of its own. The keyboard shapes the environment rather than triggering every voice, making the device a living generative instrument.
